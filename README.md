Welcome to the official web portal for **EUPHORIA '26**, the premier even-semester inter-college cultural, technical, and sports festival!

---

## ✨ Features

- 🎭 **Events Showcase**: Comprehensive listing of cultural, technical, gaming, and sports competitions (`events.html`).
- 🎨 **Modern Visual Aesthetics**: Cyberpunk/steampunk inspired theme with glassmorphism, dynamic animations, and custom styling (`stylee.css`).
- 📱 **Responsive Design**: Mobile-first layouts optimized across desktop, tablet, and smartphone screens.
- 📞 **Contact & Venue Details**: Interactive contact section, venue maps, and team coordinator details (`contact.html`).

---

## 📁 Repository Structure

```text
EUPHORIA/
├── index.html        # Main landing page & festival overview
├── events.html       # Detailed events list, rules & registration
├── contact.html      # Contact form, location map & coordinator info
├── stylee.css        # Core stylesheet with animations & layouts
├── README.md         # Project documentation
└── [images & assets] # Event banners, posters, icons & theme media
```

1. **Clone the Repository:**
   ```bash

   cd euphoria-even-semester
   ```

2. **Run Locally:**
   - Open `index.html` in any web browser.
